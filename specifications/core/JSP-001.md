# JSP-001 — JRE Core Specification

Status: DRAFT
Version: 0.1.0

## Objective

JRE is a modular computational reasoning engine for Jyotisha.

## Operating Modes

### Mode A — Universal Gochar

Requires:
- Current astronomical state
- Rashi
- Nakshatra
- Transit configuration

Does not require personal birth data.

### Mode B — Personal Kundali

Requires:
- Birth date
- Birth time
- Birth location
- Calculation configuration

May additionally use:
- Dasha
- Vargas
- Shadbala
- Yogas
- Historical events
- Current location/time

## Architectural Layers

1. Astronomical
2. Classification
3. Knowledge
4. Calculation
5. Rules
6. Dynamic State
7. Inference
8. Explanation

## Fundamental Rule

Astronomical calculations must remain deterministic and independently testable.

Interpretation must never alter astronomical calculations.

## Versioning

New knowledge and rules must be versioned.

Existing calculations must not be silently changed.

## Validation

Every production calculation requires automated tests.
